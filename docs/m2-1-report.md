## 自动化

- `npm run test:m2:faux`运行Pi faux provider的确定性集成测试，进入CI。
- `.github/workflows/m2-live-nightly.yml`每天定时运行真实Electron回归；没有配置密钥时脚本安全跳过，不把凭据写入仓库或日志。
- `npm test`、`npm run typecheck`、`npm run lint`、`npm run build:desktop`和`npm run test:desktop`均通过。

## 已知边界

审批中的工具调用和上下文不会跨进程继续执行；重启后会过期并提示重新发起，这是M2.1的明确边界。M3再持久化待执行调用和Pi上下文，实现一键继续。fallback已接入运行时，但需要单独的供应商故障注入回归来验证切换事件和备用模型输出。
