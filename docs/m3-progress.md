# M3 当前进度

日期：2026-10-04

本轮先完成M3.0和M3.1的可复用地基，并把M2.1遗留项接到产品链路：

- Electron worker现在只做消息路由，运行编排位于`packages/runtime/src/runs/executor.ts`。
- faux运行和真实运行共用同一套Executor接口；主模型故障会产生`run.fallback`，且已有工具副作用时不会重复从头运行备用模型。
- 审批事件包含相对路径、字数和粗粒度行差异；权限拒绝产生确定性的群聊提示，重载后工具保持中文标签。
- `tasks`和`run_snapshots`已加入SQLite迁移。任务图、声明式工作流校验、工作流运行器、费用估算均为纯runtime模块并有单测。
- 审批快照包含Pi消息、系统提示、模型引用和待执行工具调用；有快照的等待审批运行不会在启动时被清扫。重启后批准会恢复原运行并继续写盘；无快照的旧运行仍会被标记为中断。
- 设置页新增“章节定稿后自动评审”开关，默认关闭；运行前会显示输入、输出和费用预估。单次运行默认不设硬预算上限。
- 夜间真实回归在缺少`DEEPSEEK_API_KEY`时只有本地运行可跳过，CI通过`WORDHUB_REQUIRE_LIVE=1`明确失败。

已验证：`validate:schema`、`typecheck`、`npm test`（8个测试文件、32项）、`test:m2:faux`（5项）、`lint`、桌面构建、桌面冒烟和M1重启E2E（11/11）。

仍需在后续M3任务中完成：多节点工作流接入运行入口和UI、质询裁决事件驱动的任务暂停/继续、并发任务的任务级UI泳道、项目预算持久化与超预算暂停、真实模型的完整`write-chapter-full`回归。
