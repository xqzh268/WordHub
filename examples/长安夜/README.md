# 《长安夜》

这是WordHub的M3集成回归样例，不是创作正文。设定集写明“裴照是左撇子”，第三章故意写成“右手按刀”，用于验证评审质询、裁决与返工链路。

本目录保留故意制造的矛盾，方便核对评审依据。不要在文档整理时将第三章改成无矛盾稿；真实回归脚本会在临时项目中准备各自的设定和章节。

- `npm run test:m3:live`检查升级、裁决、返工、纸面章节文字与工作流收尾。
- `npm run test:m3:neutral`使用不提示矛盾类型的评审请求，度量预埋矛盾检出与无矛盾章节误报。
- 两条脚本均需预先构建桌面，并在进程环境提供真实模型密钥；缺密钥时默认跳过，`WORDHUB_REQUIRE_LIVE=1`时失败。

M4首个真实创作题材默认沿用唐代悬疑。当前这些数行文字不足以支持“一句话→问答→前三章”的验收；完整人物、情节梗概与设定仍需审阅确认后扩写。具体状态见[M4进展](../../docs/m4-progress.md)。
